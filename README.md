<h1>🌌 AstroShatter</h1>

<p><strong>AstroShatter</strong> is a fun, fast-paced <strong>arcade-style shooter game</strong> built with <strong>C++, Qt Widgets, and CMake</strong>.<br>
Your mission: <em>destroy big asteroids before they pass by</em>. If even a single asteroid escapes, the game ends! Survive as long as you can and set a new high score.</p>

<h2>🎮 Gameplay</h2>
<ul>
  <li>Pilot your ship and <strong>shoot incoming asteroids</strong></li>
  <li>Don’t let any asteroid <em>pass out of the screen</em></li>
  <li>The game ends immediately if one escapes</li>
  <li>Challenge yourself to stay alive as long as possible</li>
</ul>

<h2>✨ Features</h2>
<ul>
  <li>Classic arcade-style action</li>
  <li>Responsive controls with <strong>Qt Widgets</strong></li>
  <li>Increasing difficulty over time</li>
  <li>Score tracking</li>
</ul>

<h2>⚙️ Built With</h2>
<ul>
  <li><strong>C++</strong> – core game logic</li>
  <li><strong>Qt Widgets (Qt Creator)</strong> – cross-platform GUI</li>
  <li><strong>CMake</strong> – build system</li>
</ul>

<h2>📦 Installation & Build Instructions</h2>

<h3>Prerequisites</h3>
<ul>
  <li><a href="https://cmake.org/">CMake</a> (3.14 or higher recommended)</li>
  <li><a href="https://www.qt.io/">Qt 5</a> or <a href="https://www.qt.io/">Qt 6</a></li>
  <li>C++17 compatible compiler</li>
</ul>

<h3>Build Steps</h3>
<pre><code>git clone https://github.com/yourusername/AstroShatter.git
cd AstroShatter
mkdir build
cd build
cmake ..
cmake --build .
./AstroShatter
</code></pre>
<p><em>Alternatively, open the project directly in <strong>Qt Creator</strong>, configure, and build there.</em></p>
